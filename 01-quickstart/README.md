# 01 — Quickstart

Minimal, runnable quickstarts for getting up and running with Claude on Google Cloud.

| Quickstart | Description |
|---|---|
| [`otel-bq/`](./otel-bq/) | Ship Claude Code usage, cost and productivity telemetry into Google Cloud Observability, via the Google-built OpenTelemetry Collector on Cloud Run |
| [`telemetry-api-otel-bq/`](./telemetry-api-otel-bq/) | Ship Claude Code OpenTelemetry logs straight to BigQuery via the Telemetry API — no collector to deploy. Cost, tool, hook and session analytics in SQL |
